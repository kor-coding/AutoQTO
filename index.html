Workflow

How it works

Four steps from drawing to deliverable.

Typical workflow: Open PDF → Switch to CAD → set scale → Hide Drawings if needed → Identify Rooms → Generate Centerlines → Edit Areas → Quantity Take-Off dock → Save PDF. Paid plans can use Auto Bot for the detection chain and 3D View for vertical areas. See the full checklist inHow a takeoff usually runs.

  1. Open the drawingLoad a PDF, browse in PDF view, then Switch to CAD and set scale.
  2. Detect geometryHide clutter, Identify Rooms, Generate Centerlines, and optionally Rooms Offset.
  3. Refine & calculateEdit Areas, organise the Quantity Take-Off dock, and apply formulas.
  4. ExportExport to Excel or Save PDF for PDF XChange and other readers.
