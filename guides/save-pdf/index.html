Save PDF

Save PDF writes the current page with takeoff marks: rooms as Area measurements, centerlines as dashed lengths, page scale, and session data so Open → CAD can restore the session. Re-saving replaces older takeoff marks from this app.

When to use

When you want a shareable annotated PDF (for example in PDF XChange) or to resume the same page later with session restore.

Steps

  1. Finish geometry on the pageComplete rooms, centerlines, and edits you want embedded on this sheet.
  2. Save PDFRun Save PDF (waiting panel possible). Rooms save as Area measurements (translucent, with live area/perimeter in PDF XChange). Centerlines save as dashed lengths — orange internal, blue external. Page scale and session data are included.
  3. Re-open and restoreAfter Open PDF and Switch to CAD, session data can restore takeoff so you can continue with Edit Areas. Re-save replaces older takeoff marks from this app on that page. See Reopen previously measured PDF.

Tips & warnings

Note

Other readers show fills if they support the current exporter’s annotations. PDF XChange is the reference for live area/perimeter on Area measurements.

Warning

Re-save replaces previous takeoff marks from this app on the page — keep a copy if you need an earlier mark-up revision.

Tip

Session restore is available to all users who saved with Save PDF — you do not need a paid plan to reopen and continue editing.
