Open PDF

Open PDF is the entry point for every takeoff. It loads a vector PDF into the viewer so you can browse quickly before switching to CAD for analysis.

When to use

At the start of a session, or whenever you need a different drawing file.

Steps

  1. Choose Open PDFUse the toolbar or file command to select a vector PDF drawing.
  2. Page 1 in PDF viewThe first page loads in PDF view — a fast pan/zoom preview. Analysis tools such as Identify Rooms are not available until you Switch to CAD.
  3. What becomes availableOpening enables Save PDF, Prev / Next Page, and Switch to CAD so you can move through sheets and start takeoff.

Tips & warnings

Tip

Prefer clean vector PDFs. Scanned rasters and heavy mark-up make detection harder.
