Save and load template

Save and load template is an Enterprise-only feature for collaborative quantity workflows. From the Template button on the top row of the Quantity Take-Off dock, you can save your user-defined column headers and later load that template on a new project so the dock columns match your team’s standard.

When to use

When several estimators share the same user columns and formulas layout across projects, and your organisation is on an Enterprise pack.

Steps

  1. Set up columns on a projectIn the Quantity Take-Off dock, add the user-defined column headers (and related setup) your team needs. See User columns and formulas.
  2. Open Template on the dockOn the top row of the Quantity dock, open the Template button dropdown.
  3. Save templateChoose Save template to export the current user-defined column headers for reuse.
  4. Load template on a new projectOn a new project, open Template → Load template and restore those headers so the dock matches your saved layout.

Tips & warnings

Note

Save and load template is Enterprise only. Individual paid plans include Auto Bot and 3D View but not this template workflow.

Tip

Save a template once your column names are stable — then load it at the start of each new project instead of re-adding columns by hand.
