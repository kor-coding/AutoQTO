Export to Excel

Export to Excel writes the Quantity Take-Off tree as currently shown, including built-in and user columns with computed formula values, to an .xlsx file.

When to use

When you need a spreadsheet for estimating, review, or archival alongside the drawing.

Steps

  1. Arrange the dockShow, hide, and name rows as you want them to appear — the export matches the tree as shown.
  2. Export to ExcelRun Export to Excel. A waiting panel may appear while the workbook is built.
  3. Open the .xlsxBuilt-in and user columns export with computed values ready for your estimating workflow.

Tips & warnings

Note

Hidden rows follow the dock’s current presentation — tidy visibility before you export if the sheet should omit them.
