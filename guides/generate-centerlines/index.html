Generate Centerlines

Generate Centerlines needs identified rooms. You set the smallest and largest wall gap in mm (defaults 50–350). Orange dashed lines are internal; blue are external. Success unlocks Rooms Offset.

When to use

After Identify Rooms, when you need wall lengths or want Rooms Offset area modes that depend on centerlines.

Steps

  1. Ensure rooms existRun Identify Rooms first so there is room geometry to work from.
  2. Set gap limitsIn the dialog, set smallest and largest wall gap in millimetres. Defaults are 50–350 mm.
  3. GenerateConfirm. A waiting panel may appear. Centerlines draw as orange dashed (internal) and blue (external).
  4. Unlock Rooms OffsetWhen centerlines exist, Rooms Offset becomes available for GFA and related area modes.

Tips & warnings

Warning

If no scale is set, the tool warns and treats millimetre gap values as points — calibrate first for real-world gaps.
