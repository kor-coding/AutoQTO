User columns and formulas

Extend the Quantity Take-Off dock with user columns. Cells accept numbers, text, or =formulas using a spreadsheet-like syntax, including cross-row references that track renames.

When to use

When you need rates, wastage, derived areas, or custom fields beyond Length, Area, and Source.

Steps

  1. Add a columnUse + Add Column. The name cannot contain [ ] @ or . and must not clash with Length, Area, or Source.
  2. Edit a cellDouble-click a cell. Enter a number, text, or a formula starting with =.
  3. Formula syntaxSame-row: =@[Area] or =Area. Cross-row: =[Kitchen].[Area]. Functions: SUM, AVERAGE/AVG, MIN, MAX, ABS, ROUND, IF. Arithmetic and comparisons are supported.
  4. Fill Down and removeFill Down shifts same-group references like Excel. Header right-click removes a user column.

Tips & warnings

Note

Errors you may see: #DIV/0!, #REF!, #NAME?, #CIRCULAR!, #VALUE!, #ERROR!. Cross-row refs stick on rename; after Delete they become #REF!.

Tip

User-added column names survive Prev / Next Page even though geometry takeoff resets.
