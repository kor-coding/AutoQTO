Reopen previously measured PDF

If you used Save PDF on a sheet, you can reopen that file later and pick up where you left off. Session data restores rooms, centerlines, scale, and related marks after Switch to CAD, so Edit Areas is ready for adjustments. This is a general product capability for anyone who saved the session — not a paid-only gate.

When to use

When you need to revisit a sheet you already measured, fix polygons, or continue quantities without starting detection from scratch.

Steps

  1. Open the saved PDFUse Open PDF and choose the file you previously saved with Save PDF (the one that embedded session data and takeoff marks).
  2. Switch to CADSwitch to CAD so vectors extract and session data can restore the earlier takeoff. A waiting panel may appear; pan and zoom still work.
  3. Confirm restoreWhen restore succeeds, rooms and centerlines return as overlays and Quantity dock rows. Scale from the saved page is applied.
  4. Continue with Edit AreasTurn on Edit Areas to select, draw, split, merge, offset, or rename. Done commits; Cancel discards. Then update the dock or Save PDF again.

Tips & warnings

Tip

Save PDF before you close a long session if you expect to reopen and continue later.

Note

Changing page still clears that sheet’s live takeoff. Reopen restore applies to the saved page session — re-identify if you move to an unsaved sheet.

Warning

Re-saving replaces earlier takeoff marks from this app on the page. Keep a copy if you need a prior mark-up revision.
