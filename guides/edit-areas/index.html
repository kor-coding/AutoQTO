Edit Areas

Edit Areas lets you fix wrong polygons when you have rooms and/or centerlines. It is checkable: a second toolbar appears and other analysis tools lock until you Done or Cancel.

When to use

When automatic room or centerline polygons need vertex edits, splits, merges, offsets, or renames before quantities are trusted.

Steps

  1. Enter Edit AreasTurn on Edit Areas (checkable). A second toolbar appears; other analysis is locked.
  2. Select and reshape (S)S Select: move shapes, drag vertices, use snaps.
  3. Draw (L / C / R)L polygon, C curve, R rectangle to draw new geometry.
  4. Split, merge, offsetX Split with two clicks. M Merge. O Offset.
  5. Clipboard and renameCtrl+C / Ctrl+X / Ctrl+V, Delete, Ctrl+Z / Ctrl+Y. F2 renames. Esc cancels a draw and returns to Select.
  6. Done or CancelDone commits; Cancel discards. Leaving Edit Areas rebuilds overlays and the Quantity tree.

Tips & warnings

Warning

Other analysis tools stay locked while Edit Areas is active — finish with Done or Cancel before running Identify Rooms again.

Tip

Returning to a sheet you saved earlier? Open the measured PDF, Switch to CAD to restore session data, then continue in Edit Areas — see Reopen previously measured PDF.
