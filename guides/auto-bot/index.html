Auto Bot

Auto Bot is a paid, agent-style workflow. One button starts a sequence of key take-off steps. Each function it runs behaves like the manual tool — the same windows and prompts appear when clarification is needed (human-in-the-loop). You can Pause and Resume to edit mid-run, or Stop to shut the agent off at the current milestone.

When to use

When you want the usual detection chain on a floor plan without clicking each tool in turn — and you have an Individual or Enterprise subscription that includes Auto Bot.

Steps

  1. PrerequisitesOpen a vector PDF and Switch to CAD so the sheet is ready for analysis. Hide Drawings first if clutter would confuse room detection.
  2. Start Auto BotPress the Auto Bot button. The agent begins the sequence: Find Grid, Identify Rooms, Generate Centerlines, then Rooms Offset (Offset Rooms).
  3. Answer prompts as usualWhen a step needs input (for example Confirm Grid Dimension Scale, wall-gap limits, or Rooms Offset mode), the same dialogue or panel appears as for the manual feature. Respond, then the agent continues.
  4. Pause and ResumePause stops the agent between milestones so you can edit (for example in Edit Areas). Resume continues from the next pending step.
  5. StopStop fully shuts off the agent at whichever milestone it has reached. Completed steps remain; unfinished ones are not run until you start again or use the manual tools.

Tips & warnings

Note

Auto Bot is a paid feature (Individual and Enterprise). Free use still has the manual tools.

Tip

Treat Auto Bot as a guided path through the same heuristics — always verify rooms and centerlines before tender figures.

Warning

Stop does not undo work already finished in the run; it only prevents further automatic steps.
