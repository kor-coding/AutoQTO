Workflow · 01

How a takeoff usually runs

Most sheets follow the same rhythm: open and browse, switch to CAD, set scale, tidy clutter, identify rooms, generate centerlines, fix polygons if needed, then work the Quantity Take-Off dock and save. This overview links each step to the dedicated guide.

When to use

Use this as your checklist on a new floor plan. Jump into the linked articles when you need the full behaviour of a tool.

Steps

  1. Open PDF and browse in PDF viewOpen a vector PDF. Page 1 loads in PDF view for fast pan and zoom. Save PDF, page buttons, and Switch to CAD become available. See Open PDF and PDF view vs Switch to CAD.
  2. Switch to CADSwitch to CAD so vectors extract in the background and rooms/walls can become live overlays. A waiting panel may appear; you can still pan and zoom.
  3. Find Grid Extents (optional) or Calibrate ScaleRun Find Grid Extents to locate grid clusters and, if dimension text is found, confirm scale. Otherwise use Calibrate Scale with two points on a known length.
  4. Hide Drawings if neededIf ticks, dimensions, or other strokes pollute wall detection, use Hide Drawings so Identify Rooms ignores those colours and strokes.
  5. Manual geometry — or Auto Bot (paid)Identify Rooms, Generate Centerlines, and optionally Rooms Offset by hand, or start Auto Bot (paid) to run Find Grid, Identify Rooms, Generate Centerlines, and Rooms Offset in sequence with the same prompts as the manual tools. Pause/Resume to edit mid-run; Stop ends at the current milestone.
  6. Identify RoomsDetect enclosed rooms (door openings closed with red dashed bypasses while running). Result: translucent polygons, labels, and Quantity dock numbers. Unlocks Edit Areas and Generate Centerlines.
  7. Generate Centerlines, then Rooms Offset (optional)Generate Centerlines with wall-gap limits (defaults 50–350 mm). Optionally run Rooms Offset for GFA, all-centerline, or outer-face area modes.
  8. Edit Areas if a polygon is wrongEnter Edit Areas to select, draw, split, merge, offset, or rename. Done commits; Cancel discards. Leaving rebuilds overlays and the Quantity tree.
  9. Quantity Take-Off dockName items, hide or delete rows, add user columns and formulas, then Export to Excel when ready.
  10. Save PDFSave the current page with rooms as Area measurements, centerlines as dashed lengths, page scale, and session data for restore after Open → CAD (for PDF XChange and other readers that show the fills).
  11. Reopen later (optional)To continue later, open the saved PDF, Switch to CAD so session data restores, then use Edit Areas. See Reopen previously measured PDF.

Tips & warnings

Warning

Analysis is per page. Prev / Next Page clears rooms, centerlines, and overlays on that sheet. User-added column names stay.

Note

Always verify heuristic detections against the drawing before relying on tender figures.

Tip

Paid subscribers can use Auto Bot to chain the main detection steps, and 3D View for vertical area. Enterprise packs also get Save/Load Template for dock columns.
